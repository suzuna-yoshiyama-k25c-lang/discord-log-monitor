# 🦊 Discord ログイン監視ツール

## 📌 これは何？
Linuxサーバーのログイン記録（`/var/log/secure`）を1秒ごとに見張り、不審なログイン失敗（不正アクセス）があったら、自分のDiscordにリアルタイムで通知するPythonプログラムです。
大学の実習・個人の勉強として作成しました。

## 🛠️ 使い方
1. `monitor_log.py` をサーバー上の好きな場所に配置する。
2. 以下のコマンドで、管理者権限で実行する。
   ```bash
   sudo python3 monitor_log.py
   ⚠️ こだわりポイント（ロボット対策）
インターネット上の自動攻撃ロボット（ボット）が1秒間に何十回も無差別攻撃を仕掛けてくるため、通常のままだと通知が鳴り止まなくなります。
そのため、ログの中に自分のユーザー名である「alma」という文字が含まれているログイン失敗のみを検知して通知するよう、条件を厳しくカスタマイズしてあります。
